## ✨ Overview

This portfolio is built as a professional and interactive representation of my journey as a **Software Systems student and aspiring full-stack engineer**.

Rather than functioning as a traditional static resume website, it combines modern application engineering with an immersive visual experience.

### Core Highlights

- Premium Liquid Glass interface
- Futuristic light and dark themes
- Interactive 3D environment
- Three.js / React Three Fiber
- Framer Motion transitions
- Anime.js-powered UI motion
- Cinematic 3D loading experience
- Animated project showcase
- Interactive skill presentation
- Professional and coding profiles
- MongoDB Atlas-backed portfolio data
- MongoDB GridFS file storage
- PDF-only resume viewing and downloading
- Resend-powered contact email delivery
- Responsive and performance-aware architecture

# 📧 Contact Email Architecture

The portfolio uses a server-side Resend email workflow.

```text
Visitor
   ↓
React Contact Form
   ↓
POST /api/contact
   ↓
Node.js + Express
   ↓
Resend API
   ↓
Gmail Inbox
```

### Routing

**From**

Approved Resend sender

**To**

```text
akileshanand302006@gmail.com
```

**Reply-To**

Visitor's submitted email

This keeps email delivery on the backend and allows direct replies to the visitor.

# ⚙️ Local Development

## Clone

```bash
git clone https://github.com/akileshanand302006-sketch/Akilesh-A-Software-Systems-Portfolio.git

cd Akilesh-A-Software-Systems-Portfolio
```

## Install Frontend Dependencies

```bash
npm install
```

## Install Backend Dependencies

```bash
cd server
npm install
```

## Backend Environment

Create:

```text
server/.env
```

Example:

```env
PORT=5000

MONGODB_URI=your_mongodb_atlas_connection_string

CLIENT_URL=http://localhost:5173

RESEND_API_KEY=your_resend_api_key

CONTACT_TO=akileshanand302006@gmail.com
```

Never commit `.env`.

## Start Backend

```bash
npm run dev
```

## Start Frontend

From the project root:

```bash
npm run dev
```

Open:

```text
http://localhost:5173
```

# 🌐 Deployment

## Frontend — Netlify

The production React/Vite frontend is deployed through Netlify.

### Build

```bash
npm run build
```

### Publish Directory

```text
dist
```

### Production URL

```text
https://akilesha-portfolio.netlify.app/
```

### Deployment Flow

```text
GitHub Repository
       ↓
Netlify
       ↓
npm run build
       ↓
dist/
       ↓
Production Website
```

Netlify handles the public frontend deployment while the application continues communicating with the existing backend through HTTPS.

---

## Backend — Render

The existing Node.js + Express backend remains separate from the frontend.

```text
Netlify
   ↓
Render
   ↓
Node.js + Express
```

The backend is intended to run on an **always-on production compute plan** so that it remains continuously available without free-tier sleep behavior.

The backend continues to manage:

* API routes
* MongoDB Atlas
* GridFS
* Contact processing
* Resend
* Resume delivery
* Analytics
* Other server-side functionality

---

## Database — MongoDB Atlas

MongoDB Atlas remains the production database.

```text
Render Backend
      ↓
MongoDB Atlas
      ↓
GridFS
```

No MongoDB server is required on Netlify.

---

## Email — Resend

The production contact flow is:

```text
Netlify
   ↓
Render Backend
   ↓
Resend API
   ↓
Gmail Inbox
```

The Resend API key remains backend-only.

# 🔒 Security

The project follows backend-first security principles:

* Resend API keys remain server-side
* MongoDB credentials remain server-side
* Backend secrets are not bundled into React
* Contact input is validated
* User content is sanitized before email formatting
* Sensitive server errors are not exposed
* `.env` is excluded from Git
* Frontend only receives public configuration
