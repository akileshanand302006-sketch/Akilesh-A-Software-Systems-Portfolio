## ✨ Overview

This portfolio is built as a professional and interactive representation of my journey as a **Software Systems student and aspiring full-stack engineer**.

Rather than functioning as a traditional static resume website, it combines modern application engineering with an immersive visual experience.

### Core Highlights

- Premium Liquid Glass interface
- Futuristic light and dark themes
- Interactive 3D environment
- Three.js / React Three Fiber
- Framer Motion transitions
- Anime.js-powered UI motion
- Cinematic 3D loading experience
- Animated project showcase
- Interactive skill presentation
- Professional and coding profiles
- MongoDB Atlas-backed portfolio data
- MongoDB GridFS file storage
- PDF-only resume viewing and downloading
- Resend-powered contact email delivery
- Responsive and performance-aware architecture

# 🎨 Design System

The portfolio uses one unified visual language across both themes.

## 🌑 Dark Liquid Glass

The dark experience combines:

- Deep-space backgrounds
- Translucent dark glass
- Cyan illumination
- Electric-blue highlights
- Violet accents
- Floating 3D geometry
- Orbital rings
- Particle/network systems
- Luminous borders
- Soft bloom
- Cinematic depth

## ☀️ Light Liquid Glass

The light experience is a complete Liquid Glass system rather than a plain white theme.

It uses:

- Atmospheric white/blue backgrounds
- Frosted translucent surfaces
- Electric-blue accents
- Cyan illumination
- Subtle violet lighting
- Glass reflections
- Luminous borders
- Cool shadows
- Layered transparency
- 3D depth
- Premium glow effects

Both themes share the same:

- Component hierarchy
- Spacing
- Typography
- Interaction patterns
- Animation language
- Responsive behavior

---

# 🌌 Interactive 3D Experience

The portfolio includes an immersive 3D environment powered by:

- Three.js
- React Three Fiber
- Drei
- Floating geometry
- Orbital systems
- Particle networks
- Atmospheric lighting
- Camera motion
- Subtle parallax
- Glass-inspired materials
- Theme-aware lighting

The 3D environment is intentionally treated as an atmospheric background so that it enhances the UI without interfering with readability or interaction.
